## 保留（5回試して動かなかった）

**V1（輪郭の明度差 p10）と V6（消える輪郭の割合）の6箇所** —
おうち の とびら・ふとん、うみ の いわ、のうじょう の こや・さく、
きょうりゅう の きかぶ・たまご。

試したこと（すべて棄却）: ①輪郭のまわりの暗がり ②焼き込む陰影の幅を広げる
③光の色を明るさだけ戻す ④落ち影を濃く ⑤背景の明るさから値を離す
⑥明るい背景の前で暗く落とす（逆光）。

### なぜ動かないのか（2026-09-08 の実測）

7箇所の「隠れ場所の L\* の範囲」と「輪郭のすぐ外の背景の L\*」を並べて測った。

| 場所 | 隠れ場所 L\* | 背景 L\*（中央） | 背景の中央値が隠れ場所の範囲の中 |
|---|---|---|---|
| おうち/とびら | 27.2–58.0 | 37.7 | **はい** |
| うみ/いわ | 18.4–56.3 | 51.2 | **はい** |
| きょうりゅう/きかぶ | 15.3–34.8 | 25.2 | **はい** |
| きょうりゅう/たまご | 14.6–45.3 | 33.9 | **はい** |
| のうじょう/こや | 21.2–59.2 | 68.5 | いいえ |
| のうじょう/さく | 22.3–58.4 | 65.3 | いいえ |
| うみ/つぼ | 10.9–42.3 | 48.3 | いいえ |

**上の4箇所は原理的に通せない。** 背景の明るさが隠れ場所自身の明暗の
範囲の内側にあるので、輪郭のどこかは必ず背景と同じ明るさになる。
V1 は輪郭のいちばん弱い 10% を見るので、そこが引っかかる。

しかも**形に沿った勾配を強くするほど、隠れ場所の明暗の幅は広がる**ので、
判定が求める「面の明暗を勾配で作る」と V1 は互いに引っ張り合う。

下の3箇所は離せる余地があるが、⑥で試したところ、対象は良くなる代わりに
もともと足りていた箇所が背景に寄って**全体では悪化**した（12 → 15件）。

**判定は baseline の時点で「絵では4つとも一目で見つかる。色相で分離している。
よって −20（埋もれて分からない）は適用していない」と書いている。**
V1/V6 は明度差しか見ないので、色相だけで分かれている組を落第にする。
基準を動かすのは人間の判断なので、ここは触らずに残す。
