## 保留（5回試して動かなかった）

**V1（輪郭の明度差 p10）と V6（消える輪郭の割合）の6箇所** —
おうち の とびら・ふとん、うみ の いわ、のうじょう の こや・さく、
きょうりゅう の きかぶ・たまご。

試したこと（すべて棄却）: ①輪郭のまわりの暗がり ②焼き込む陰影の幅を広げる
③光の色を明るさだけ戻す ④落ち影を濃く ⑤背景の明るさから値を離す。

**判定は baseline の時点で「絵では4つとも一目で見つかる。色相で分離している。
よって −20（埋もれて分からない）は適用していない」と書いている。**
V1/V6 は明度差しか見ないので、色相だけで分かれている組を落第にする。
基準を動かすのは人間の判断なので、ここは触らずに残す。
