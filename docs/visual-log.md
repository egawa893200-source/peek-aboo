**採点の測り方を1つ直した（サイクル9の途中）。** 落ち影とハローが
「隠れ場所の画素」の切り出しに混ざって、輪郭の明度差が壊れていた。
`setShadowsVisible` でハローも消し、輪郭の外側は**画面に出ている絵**から取る
（背景だけの1枚は切り出しにしか使わない）。**閾値は変えていない。**
同じコードで baseline を測り直すと 55件（前の測り方では 56件）。
